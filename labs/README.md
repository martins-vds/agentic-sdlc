# Labs

The student-facing instructions live in `docs/modules/`. This directory groups the practical themes:

- `labs/01-foundations/README.md` - agent contract exercise
- `labs/02-sdlc-integration/README.md` - artifact handoff exercise
- `labs/03-tooling-mcp/README.md` - tool boundary exercise
- `labs/04-multi-agent/README.md` - concurrent specialist exercise and embedded Project Pulse custom-agent lab
- `labs/05-memory-evaluation/README.md` - state and quality gates
- `labs/06-governance/README.md` - guardrails and recovery

Run `./scripts/validate_workshop.sh` from the repository root to verify that all lab references and implementations are present.
